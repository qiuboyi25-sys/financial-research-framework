# Public data policy

本仓库遵循“代码公开、数据不随库分发”的边界。

## 不进入版本控制

- 原始或加工后的真实市场数据；
- 商业数据供应商文档和SDK适配器；
- API密钥、访问令牌、账户、数据库地址和许可证文件；
- 本地绝对路径、缓存、HTML/CSV研究输出；
- 由非公开研究材料直接复制的表格、持仓和参数。

## 可以公开

- 与数据源无关的字段契约和校验逻辑；
- 通用因子、预处理、评价和组合算法；
- 固定随机种子生成的合成数据；
- 不访问网络的测试；
- 用户自行提供CSV/Parquet的文件适配器。

## 扩展建议

如需连接新的数据源，请在私有扩展包中实现`MarketDataProvider`协议，并通过环境变量或密钥管理服务读取凭据。不要在本仓库中写入默认令牌、内网地址或真实响应样例。
